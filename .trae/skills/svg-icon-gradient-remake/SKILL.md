# SVG图标基于原始底色制作左上‑右下渐变

> 
> 核心约束：**只新增渐变定义，绝不修改图形路径，保留原图风格，模拟左上角光源打光效果，适配16px小尺寸UI图标**

## 何时使用

- 需要给现成SVG图标增加渐变效果，不想改变图标外形轮廓
- 希望渐变色调和原版图标配色一脉相承，不使用完全无关的新色系
- GitHub README / Markdown 使用16×16小图标（单层文件夹、带徽章多层复合图标等）
- 要求固定光源：**左上角最亮，右下角最深**

## 核心心法

1. **路径完全不动，仅修改fill**：所有`<path>`的`d`属性完整原样复制，禁止改动坐标，只替换`fill`值为渐变引用。
2. **以原图底色为色相根基**：读取每个path原始`fill`色值作为基准；
   - 左上角 `offset="0%"`：同色相做提亮高光；
   - 中间offset（可选）：贴近原图原始基准色；
   - 右下角 `offset="100%"`：同色相加深，允许轻微偏移邻近色，禁止跳转到完全无关色系。
3. **固定渐变方向**：`x1="0%" y1="0%" x2="100%" y2="100%"`，保证左上亮，右下暗。
4. **分层独立处理**：多层多path图标，每一层使用自身原始底色独立生成渐变，分配唯一渐变ID；小徽章/角标装饰层压低明暗反差，防止小像素丢失细节。
5. **渐变统一收纳在defs**：全部`<linearGradient>`写在`<defs>`内部，放在所有path标签之前，defs不会渲染出图形。

## 黑名单（务必避免）

- ❌ 修改path的`d`路径字符串，改动图标轮廓坐标
- ❌ 脱离原图底色，直接选用完全无关色系做渐变
- ❌ 16px小图标高光过度接近纯白、暗部颜色过重，造成图标轮廓糊掉
- ❌ 多层path共用同一个渐变ID
- ❌ 将linearGradient放到defs标签之外，或者写在path标签之后

## 推荐实现手法

### 单层图标（普通文件夹）

1. 提取path原始`fill`基准色；
2. defs内定义`linearGradient`，方向固定左上→右下；
3. stop设置：0%提亮高光，中间可选还原基准色，100%同色系加深；
4. path的fill改为`url(#渐变ID)`，d保持原样。

### 多层复合图标（folder‑admin‑open这类带徽章装饰）

1. 逐个提取每一个path的原始fill基准色；
2. 主体图形可以设置适中明暗差；
3. **细小装饰path必须减弱渐变反差**，保护微小细节；
4. 每个渐变设置独一无二id，各path分别引用；> 
> 备选方案：装饰path直接保留原始纯色，仅主体图形应用渐变。

## 通用模板

```
<svg viewBox="0 0 16 16" xmlns="[http://www.w3.org/2000/svg](http://www.w3.org/2000/svg)">
  <defs>
    <linearGradient id="GradId" x1="0%" y1="0%" x2="100%" y2="100%">
      <stop offset="0%" stop-color="【同色相提亮，左上高光】"/>
      <stop offset="50%" stop-color="【可选：原图基准底色】"/>
      <stop offset="100%" stop-color="【同色相加深，右下暗部，允许轻微邻近色偏移】"/>
    </linearGradient>
  </defs>
  <!-- d字符串完整复制原始，仅修改fill引用渐变ID -->
  <path d="原始d字符串" fill="url(#GradId)"/>
</svg>
```

## 常见坑与修复对照

| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 图标形状变形 | 修改了path的d属性 | d字符串全部原样复制，只改动fill |
| 渐变风格和原图割裂 | 没有基于原图底色，随意选色 | 以原始fill色作为色相基准，只做提亮/加深，可轻微偏移邻近色 |
| 小图标细节糊掉看不清 | 明暗对比度过大 | 降低stop之间亮度差；装饰徽章优先弱渐变或者直接纯色 |
| 渐变方向反，右下角亮左上角暗 | x1/y1 x2/y2写反 | 固定：`x1="0%" y1="0%" x2="100%" y2="100%"` |
| 多层图标渐变失效/错乱 | 多个渐变使用同一个id | 每一套渐变分配唯一id，path引用各自对应的id |

## 执行流程建议

1. 复制完整原始SVG源码，记录每一个path的原始`fill`基准色。
2. 在SVG头部增加`<defs>`区块，定义对应数量的linearGradient。
3. 固定渐变方向`0% 0% →100% 100%`，按照「提亮‑基准‑加深」设置stop色。
4. 修改各个path的fill属性引用对应渐变ID，d属性完全不动。
5. 渲染预览：观察左上角是否高光、右下角是否自然加深，检查小装饰细节是否清晰。
6. 微调stop色值，避免过曝或者暗部糊化。
